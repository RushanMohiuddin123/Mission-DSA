## 📈 My Approach

For every problem, I try to follow a structured process:

```text
Understand the Problem
        ↓
Identify the Pattern
        ↓
Think of a Brute Force Solution
        ↓
Optimize the Approach
        ↓
Write the Code
        ↓
Analyze Time & Space Complexity
        ↓
Test the Solution
```

The focus is on **understanding why a solution works**, rather than simply memorizing code.
